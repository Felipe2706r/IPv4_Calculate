# IPv4 Calculate
Este es un proyecto realizado con fines de apoyo y estudio académico dentro del contexto de aprendizaje y practica para Subnetting (Cálculo y división de redes).

## Stack
- Lenguaje: Python (Versión 3.14.6)
- Bibliotecas: Tkinter (prototipo), CustomTkinter y Pillow
- IDE: Visual Studio Code (Versión 1.131.0)

## Estructura del proyecto
- `[IPv4 Calculate]/` — Ubicación actual destinada para almacenar los archivos de código, gráficos y configuración de la solución final del proyecto.
- `[scripts_prototipo]/` — Archivos de código que contienen el funcionamiento lógico en materia de interacción con el usuario, almacenamiento de valores, calculo de valores y muestra por medio de terminal.
- `[tkinter_prototipo]/` — Archivos de código que implementan elementos propios de las bibliotecas 'Tkinter' y 'Pillow' para generar un prototipo funcional de la interfaz gráfica de la aplicación, manteniendo el flujo original de entradas de usuario y muestra de valores calculados.
- `[recursos_graficos]/` — Imagenes de uso para las pantallas de la aplicación en materia de interfaz gráfica. 

## Convenciones
- Estilo de nombres: Utilizar snake_case para nombres de variables y funciones.
- Elementos gráficos: Utilizar unicamente elementos correspondientes de la biblioteca 'CustomTkinter' para la solución final.
- Analisis de referencia: Analizar, comprender y evaluar los prototipos presentes en `scripts_prototipo/` y `tkinter_prototipo/` para entender la naturaleza de uso y proposito de la solución final.
- Documentación interna: Generar comentarios practicos para elementos que se consideren necesarios.
- Respeto de lógica y estructura: Mantener el patron de diseño y programación utilizado en los prototipos actualizandolo para la biblioteca 'CustomTkinter'.
- Separación de archivos: Mantiene la separación de archivos de uso dependiendo su contenido y función principal (pantalla gráfica, validación de entradas de usuario, calculos).
- Importaciones: Hacer importanciones externas, ya sea de bibliotecas o de archivos locales, en el principio de un archivo o script.
- Patrón a seguir: Comprobar el funcionamiento de todas las entradas de usuario y muestras de valores antes de continuar.

## No hagas
- Límite duro: No instalar bibliotecas y/o dependencias sin avisar. En caso de haber una instalación, agregarla a `requirements.txt` con sus respectivas reglas.
- Zona prohibida: No modificar `scripts_prototipo/` y `tkinter_prototipo/`, su uso esta reservado a su lectura y análisis.
- Regla de seguridad: No subir carpeta `[__pycache__]/` de ningúna sección al
repositorio y tampoco `[docs_desarrollo]/`.
